#  YAJA MAKEUP - Sistema de Inventario y Ventas

Sistema web para la gestión de inventario, catálogo interactivo de ventas por WhatsApp y control financiero para la tienda YAJA MAKEUP.

##  Enlaces del Proyecto
* **Catálogo Público (Cliente):** https://makeup-inventory-steel.vercel.app/
* **Panel de Administración:** https://makeup-inventory-steel.vercel.app/admin

##  Credenciales de Acceso para Evaluación
* **Usuario:** `admin`
* **Contraseña:** `yaja123`

##  Tecnologías Utilizadas
* **Frontend:** React, Vite, JavaScript (ES6+), CSS3 (Flexbox/Grid), React Router DOM.
* **Backend / Base de Datos:** Supabase (PostgreSQL).
* **Despliegue / Hosting:** Vercel (SPA Rewrites via `vercel.json`).
